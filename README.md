### 🔭 Currently building — [TinyOps](https://tinyops.cc)

An enforcement and intelligence layer for developer workflows. Teams declare guardrails as
YAML rules — `trigger → condition → action` — and TinyOps evaluates them against live data
from GitHub, CI, and more.

Under the hood: a NestJS API, BullMQ workers running webhook / poll / schedule triggers, a
Postgres-backed rule engine, a **shadow mode** that dry-runs rules against production data
before they're allowed to act, and an **MCP server** so the whole system is drivable from an
AI agent.

Designed and built solo — API, workers, rule engine, frontend, and infrastructure.
